# AI Usage Widget

A small WPF widget for the Windows taskbar that shows your current Codex and Claude usage limits in one compact three-row tile.

Requires [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8) (x64 or ARM64).

![Screenshot](screenshot.png)

## Installation

1. Download `ClaudeUsageWidget-win-x64.exe` (or `win-arm64`) from [Releases](../../releases)
2. Place the exe anywhere (e.g. `C:\Tools\ClaudeUsageWidget.exe`)
3. Run it — the widget docks in the taskbar, just left of the system tray
4. Right-click the widget → Settings → **Run at startup** to launch it automatically on login

## What it shows

One row per usage limit, Codex first, then Claude:

```
[X] ●  3%      2h 58m
[X] ● 61%    119h 44m
[C] ● 89%      5h 36m
```

- **Icon** — blue **X** for Codex, orange **C** for Claude
- **Dot** — color fades smoothly from green (0%) through yellow to red (100%)
- **Percent** — how much of the limit is used
- **Countdown** — time until the limit resets

If an account can't be read, its row shows a red **Error**; hover it to see the reason. Double-click the docked widget to refresh immediately; otherwise it refreshes every minute.

## Settings

Right-click the widget to open Settings — in floating mode, Ctrl + right-click (it pops up right above the widget):

- **Claude / Codex** — show or hide each service
- **Tile width** — widget width in px
- **Primary monitor only** — don't show on secondary taskbars (applies after restart)
- **Floating mode** — detach the widget from the taskbar; it stays on top of other windows and is click-through, so clicks, hover and scrolling go to the app underneath. Hold **Ctrl** to interact with it (a blue outline appears): Ctrl + right-drag moves it, Ctrl + right-click opens Settings; the left button is ignored. Size, background and whole-window opacity are adjustable.
- **Limits** — hide individual rows (e.g. Codex 5h)
- **Notifications** — toast at 75% / 90%, and when a limit resets
- **Run at startup**
- **Quit** — exit the widget

## Credentials

**Claude:**
1. **WSL** — `~/.claude/.credentials.json` (via `wsl.exe`) — preferred
2. **Windows** — `%USERPROFILE%\.claude\.credentials.json` — fallback

**Codex:**
1. **WSL** — `~/.codex/auth.json`
2. **Windows** — `%USERPROFILE%\.codex\auth.json`

Credentials are generated by [Claude Code CLI](https://claude.ai/code) / Codex CLI when you log in.

## How it works

Claude usage is read by calling `api.anthropic.com/v1/messages` with a minimal request; the limits come back in the `anthropic-ratelimit-unified-*-utilization` / `-reset` response headers. Codex usage comes from the ChatGPT usage endpoint.

The widget automatically hides when the taskbar auto-hides or a fullscreen application is running on the same monitor.

> **Note:** This is not a native Windows widget (Win+W panel). It is a standalone borderless WPF window that pins itself to the taskbar next to the system tray and stays always on top. The native widget API requires an MSIX package and COM registration.
